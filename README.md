# EU-AI-Act

Full corpus of Regulation (EU) 2024/1689 (the EU AI Act) and its surrounding
knowledge — guidelines, national implementations, standards landscape — plus a
cross-harness compliance-analysis skill built on top of it.

Status: bootstrapping. Structure below fills in as missions land.

- `corpus/`      — source documents (EUR-Lex + Commission + member-state texts)
- `analysis/`    — structured deep-analysis outputs (obligation matrices, timelines, …)
- `skill/`       — installable EU-AI-Act compliance skill (Claude Code / Pi / Codex)
- `scripts/`     — corpus refresh + install helpers
